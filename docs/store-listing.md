# Chrome Web Store listing — ContextDrop

## Short description (≤132 chars)
Turn any webpage into a clean AI prompt pack and send it to ChatGPT, Claude, or Gemini in one click.

## Detailed description

ContextDrop captures the page you are reading, strips navigation clutter, and builds a ready-to-use prompt pack for ChatGPT, Claude, or Gemini.

**What you can do**
• One-click capture of page or selection
• Site-aware templates (article, docs, GitHub, product)
• Send to ChatGPT / Claude / Gemini or copy as prompt
• Local history of recent packs
• Keyboard shortcut Alt+Shift+D
• Right-click context menu

**Free vs Pro**
Free: 10 sends/day, 20 history items, all core capture features.
Pro: unlimited sends, cloud sync, custom templates, multi-tab research packs.
Team: shared seats for groups.

**Privacy**
Capture runs in your browser. Free mode keeps packs local. Sync only runs when you enable it with a Pro/Team license.
Privacy policy: https://YOUR_DOMAIN/privacy-policy.html

**Single purpose**
ContextDrop’s single purpose is converting web page content into AI prompt packs and sending them to AI chat tools.
