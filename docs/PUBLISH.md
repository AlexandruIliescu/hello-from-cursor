# Publishing ContextDrop (free MVP)

## Prepared in this repo
- Built zip: `extension/.output/contextdrop-0.1.0-chrome.zip` (also copied under `docs/store-screenshots/`)
- Store copy: [`store-listing.md`](store-listing.md)
- Privacy policy: [`../privacy-policy.html`](../privacy-policy.html)
- Icons: 16/32/48/128 PNG in extension public assets
- Validation mock: [`../mock/index.html`](../mock/index.html)

## Manual steps (requires your Google account)
1. Open https://chrome.google.com/webstore/devconsole and pay the one-time $5 developer fee if needed.
2. New item → upload `contextdrop-0.1.0-chrome.zip`.
3. Paste listing text from `store-listing.md`.
4. Host `privacy-policy.html` on a public URL (GitHub Pages, Netlify, or your domain) and set it in the listing.
5. Upload 1280×800 screenshots (use mock screenshots from walkthrough + store screenshots folder).
6. Submit for review.

Publishing cannot be completed from this agent environment without your Chrome Web Store credentials.
